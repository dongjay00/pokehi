# pokehi 구현 계획

> **에이전트 실행자용:** 이 계획은 superpowers:subagent-driven-development(권장) 또는 superpowers:executing-plans 스킬로 태스크 단위로 실행한다. 각 단계는 체크박스(`- [ ]`)로 진행 상황을 기록한다.

**Goal:** 셸 시작 시 로컬 캐시에서 포켓몬 한 마리를 골라 A 배치(그림 왼쪽, 정보 오른쪽) 인사 화면을 그리는 Rust CLI, 그리고 캐시를 채우는 `sync` 명령.

**Architecture:** `domain`(순수 규칙) ← `app`(유스케이스 + 포트 trait) ← `adapters`(PokéAPI HTTP, 파일 캐시, PNG) / `render`(순수 ANSI 문자열 생성) ← `cli`(옵션·환경·플랫폼·종료 코드). 모든 외부 입력(환경 변수, 날짜, 난수, TTY 여부, 터미널 폭, 네트워크)은 `cli` 경계에서 주입되므로 테스트는 네트워크와 실제 터미널 없이 돈다.

**Tech Stack:** Rust (stable, edition 2021), `clap` 4 (derive), `serde`/`serde_json`, `ureq` 2, `png`, `directories`, `chrono` (clock 기능만), `fastrand`, `unicode-width`, `terminal_size`, `enable-ansi-support`(Windows 전용). 개발 의존성: `tempfile`, `assert_cmd`, `predicates`.

**Spec:** `SPEC.md`, `PLAN.md`(도메인 설계), `RELEASE.md` — 이 계획은 세 문서를 근거로 하며, 실행자는 셋을 함께 읽는다.

## Global Constraints

- **git:** 저장소 루트는 `pokehi/` 디렉터리다(원격 `origin` = https://github.com/dongjay00/pokehi). 상위 디렉터리의 `../docs.md`(PokéAPI v2 한국어 문서)는 작업할 때 참고만 하고 저장소에 넣지 않는다.
- **커밋:** 태스크마다 마지막 단계에서 커밋한다. 메시지는 한국어로 쓰고 앞에 prefix를 붙인다(`feat:`, `fix:`, `test:`, `refactor:`, `docs:`, `ci:`, `chore:`). `git add -A`나 `git add .` 대신 태스크의 파일을 지정해서 추가한다.
- **언어:** 코드 주석, 문서, README는 한국어로 쓴다. 식별자와 API 필드 이름은 영어 그대로 둔다.
- 크레이트/바이너리 이름: `pokehi`. 라이선스 MIT.
- 인사 화면 경로는 네트워크를 절대 쓰지 않는다. 비동기 런타임 금지.
- 인사 화면 모드는 항상 종료 코드 0. `sync`의 사용법 오류 2, `--pokemon` 미발견 1, `sync` 전부 실패 1, 일부 실패 0.
- 기본 언어 `ko`, 옵션 > `POKEHI_LANG` > 기본값. 값이 없으면 en으로 대체, 그것도 없으면 줄 생략.
- 그림: 알파 < 128은 투명, 투명 여백 크롭 후 최대 32×32픽셀(32열×16행), 최근접 이웃, 확대 금지.
- 대상 종: `pokemon-species` 전체(현재 1025), 기본 폼만.
- 캐시 위치: `POKEHI_DATA_DIR` > `directories::ProjectDirs::from("", "", "pokehi").data_dir()`.
- PokéAPI: 동시 요청 ≤ 4, User-Agent `pokehi/<CARGO_PKG_VERSION>`, 받은 항목 재요청 금지.
- 테스트는 네트워크를 쓰지 않으며, 픽스처는 합성 데이터만(실제 이름·설명·그림 금지). 테스트 PNG는 코드로 생성.
- 성능: 따뜻한 캐시에서 release 빌드 실행 50ms 미만.
- 지원: Linux / macOS / Windows (cmd.exe 비지원).

## Review Focus

1. **잘린 출력 대신 엉망인 줄 맞춤** — 한국어 이름·설명과 영어 보조 이름이 섞인 줄에서 폭 계산이 틀리면 정보 열이 들쭉날쭉해진다. 기대: 모든 정보 줄이 같은 열에서 시작. → Task 7 `layout_info_column_aligned_with_korean`.
2. **아주 좁은 터미널(예: 40열)** — 기대: 그림 32열 + 간격 뒤 정보 폭이 최소 20열로 유지되고 패닉 없이 출력(가로로 넘칠 수 있음). → Task 7 `narrow_terminal_uses_min_info_width`.
3. **`sync` 도중 Ctrl+C 후 재실행** — 반쯤 쓰인 종 파일이 남으면 다음 인사에서 깨진 데이터를 읽는다. 기대: 임시 파일에 쓰고 rename하는 원자적 쓰기, 재실행 시 이어서 받음. → Task 9 `write_is_atomic_no_partial_file`.
4. **캐시는 있는데 인덱스가 비었거나 일부 종 파일만 있는 상태** — 기대: 인덱스에 있는데 파일이 없거나 깨진 종은 건너뛰고 다른 종 선택(최대 3회), 다 실패하면 안내 한 줄. → Task 10 `corrupt_species_retries_then_hints`.
5. **스프라이트가 전부 투명/1×1 같은 비정상 PNG** — 기대: 빈 스프라이트는 "그림 없음"으로 취급해 정보만 출력. → Task 3 `crop_all_transparent_is_empty`, Task 6 `empty_sprite_becomes_none`.

**Files:**
- Create: `src/render/mod.rs`(이 태스크에서는 `ColorMode` 정의와 `pub mod color;`만), `src/render/color.rs`

**Interfaces:**
- Produces:
  - `enum ColorMode { TrueColor, Ansi256, None }`
  - `fn to_ansi256(rgb: (u8,u8,u8)) -> u8` — 큐브 단계 `[0,95,135,175,215,255]`, 번호 `16 + 36r + 6g + b`; 회색조 `232 + i` (값 `8 + 10i`, i=0..23); 두 후보 중 RGB 제곱 거리 최소(동률이면 큐브)
  - `fn detect_color_mode(env: &dyn Fn(&str) -> Option<String>, windows_vt_ok: Option<bool>) -> ColorMode` — `windows_vt_ok`: 비Windows는 `None`
  - `fn fg(mode: ColorMode, rgb) -> String`, `fn bg(mode: ColorMode, rgb) -> String` — TrueColor `\x1b[38;2;R;G;Bm` / `\x1b[48;2;R;G;Bm`, Ansi256 `\x1b[38;5;Nm` / `\x1b[48;5;Nm`, None → 빈 문자열

### Task 7: 화면 렌더링 (반 블록 + A 배치)

**Files:**
- Create: `src/render/halfblock.rs`; Modify: `src/render/mod.rs` (`render` 추가)

**Interfaces:**
- Consumes: Task 4 `ColorMode`, `fg`, `bg`, `RESET`, `BOLD`, `DIM`; Task 5 `display_width`, `wrap`; Task 6 `Greeting`
- Produces:
  - `fn sprite_rows(sprite: &Sprite, mode: ColorMode) -> Vec<String>` — `ceil(h/2)`줄, 각 줄 폭 = `sprite.width`칸. 위/아래 픽셀(아래가 범위 밖이면 투명): 둘 다 투명 → `" "`; 위만 → `fg(top)▀`; 아래만 → `fg(bottom)▄`; 둘 다 → `fg(top)bg(bottom)▀`. 셀마다 색을 끝내고 다음 셀로 가기 전에 `RESET`을 넣어, 투명 셀에 배경이 새지 않게 함. 줄 끝 `RESET`.
  - `fn render(g: &Greeting, term_width: usize, mode: ColorMode) -> String`
    - 상수 `GAP = 3`, `MIN_INFO_WIDTH = 20`
    - `mode == None`이면 그림을 그리지 않는다(정보만, 이스케이프 0개, 뱃지는 `[전기]`)
    - 정보 줄: ① `BOLD{number_label} {name}RESET` + (보조 이름 있으면 `" " DIM{secondary}RESET`) ② 뱃지들: `bg(rgb) fg(글자색) " {label} " RESET`을 공백으로 연결, 글자색은 휘도 `0.299R+0.587G+0.114B > 150`이면 검정 `(0,0,0)` 아니면 흰색 ③ genus(있으면) ④ flavor를 `wrap(flavor, info_width)`한 줄들
    - `info_width = max(MIN_INFO_WIDTH, term_width - sprite_width - GAP)` (그림 없으면 `sprite_width + GAP = 0`)
    - 세로 배치: `top = (sprite_rows - info_rows) / 2` (음수면 0). 각 행 = 그림 줄(없으면 `sprite_width`칸 공백) + `GAP`칸 공백 + 정보 줄. 그림이 없으면 정보 줄만.
    - 마지막에 빈 줄 하나(`"\n"`으로 끝나는 마지막 행 뒤 `"\n"` 한 번 더)

동작 규칙:
- 언어: `--lang` > `POKEHI_LANG`(잘못된 값이면 `BadLangEnv` 경고를 stderr에 쓰고 Ko) > Ko
- 파싱: `Cli::try_parse_from`. 오류 종류가 `DisplayHelp`/`DisplayVersion`이면 clap 출력을 stdout에 쓰고 0. 그 외 오류는 인자 중 `sync`가 있으면 clap 오류를 stderr에 쓰고 2; 없으면(인사 모드) `BadArgs` 한 줄을 stderr에 쓰고 0
- 데이터 디렉터리: `POKEHI_DATA_DIR` > `ProjectDirs` (실패 시 `Corrupt`/I/O 메시지 한 줄, 인사 모드 0)
- 인사 모드: `!stdout_is_tty && !force` → 아무것도 쓰지 않고 0. 색: `--color truecolor|256`이면 강제(단 `NO_COLOR`가 있으면 None), `auto`면 `detect_color_mode`. 폭: `term_width`가 없거나 `force`이고 TTY가 아니면 80. 대상: `--pokemon` > `--today`(`Daily(ctx.today)`) > Random
- 인사 모드 오류: NoCache/VersionMismatch/Corrupt → 해당 메시지 한 줄, 0; NotFound → 메시지 한 줄, 1
- sync: 진행 상황은 stderr에 `\r` + `SyncProgress`로 덮어쓰고, 끝나면 줄바꿈 후 `SyncDone`을 stdout에 쓴다. `species_ids` 실패 또는 `saved == 0 && failed > 0` → `SyncFailed`, 1; 그 외 0

메시지 문구(정확히):

| Msg | ko | en |
|---|---|---|
| NoCache | `pokehi: 먼저 'pokehi sync'를 실행하세요` | `pokehi: run 'pokehi sync' first` |
| VersionMismatch | `pokehi: 캐시 형식이 바뀌었습니다. 'pokehi sync'를 다시 실행하세요` | `pokehi: cache format changed, run 'pokehi sync' again` |
| Corrupt | `pokehi: 캐시를 읽을 수 없습니다. 'pokehi sync'를 다시 실행하세요` | `pokehi: cannot read cache, run 'pokehi sync' again` |
| BadArgs | `pokehi: 알 수 없는 옵션입니다. 'pokehi --help'를 확인하세요` | `pokehi: unknown option, see 'pokehi --help'` |
| BadLangEnv(v) | `pokehi: POKEHI_LANG='{v}'을(를) 알 수 없어 ko를 사용합니다` | `pokehi: unknown POKEHI_LANG='{v}', using ko` |
| NotFound(x) | `pokehi: '{x}' 포켓몬이 캐시에 없습니다` | `pokehi: pokemon '{x}' not in cache` |
| SyncProgress(d,t) | `동기화 중 {d}/{t}` | `syncing {d}/{t}` |
| SyncDone | `완료: {saved}종 저장, 실패 {failed}건, 그림 실패 {sprites_failed}건` | `done: saved {saved}, failed {failed}, sprite failures {sprites_failed}` |
